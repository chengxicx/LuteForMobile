3视觉设计系统

这才是你真正想复刻的部分。它的风格不是"某个 UI 框架"，而是一套手工插图体系 + 极少的设计 token。

风格 DNA

1. 手绘蜡笔线稿

所有插图统一为：粗黑描边（约 8–10px）+ 内部斜线蜡笔纹理填充 + 圆角收笔。 不是扁平矢量，也不是拟物，是"手账涂鸦"质感。

2. 猫做主角

猫贯穿全部状态：audio_cat_waiting / listening / paused / complete， 外加 catNo / rain_cat / cat_loading01.json（Lottie 加载动画）。

3. 动物系列作为内容分类

考拉、猪、天鹅、鸭、乌贼、大猩猩、河马、熊、企鹅、犀牛—— 每个"功能入口"配一只动物，用可爱感降低学习压力。

4. 像素金币 Logo

Logo 是像素风的"円"（日元硬币）表情，蓝色像素格背景。 logo-yuan.png 对应日语 五円 = ご縁（结缘）的谐音梗。

可直接落地的代码

手绘质感的关键不是颜色，是描边。下面这个 SketchBorder 用带抖动的 Path 画边， 配合固定随机种子就能得到"手画"的轻微歪斜感： 

// lib/shared/theme/sketch_border.dart
class SketchBorder extends OutlinedBorder {
  const SketchBorder({
    this.radius = 12,
    this.jitter = 1.6,   // 抖动幅度，1.0~2.5 最自然
    this.seed = 7,
  });

  final double radius, jitter;
  final int seed;

  // 关键：用固定 seed，保证同一条边每帧抖动一致（否则会“抽搐”）
  Path _wobblyLine(Offset a, Offset b, Random r) {
    final path = Path()..moveTo(a.dx, a.dy);
    const steps = 10;
    for (var i = 1; i <= steps; i++) {
      final t = i / steps;
      final j = (i == steps) ? Offset.zero
          : Offset((r.nextDouble() - .5) * jitter,
                       (r.nextDouble() - .5) * jitter);
      path.lineTo(a.dx + (b.dx - a.dx) * t + j.dx,
                  a.dy + (b.dy - a.dy) * t + j.dy);
    }
    return path;
  }

  // getOuterPath 画内容区，getInnerPath 给裁剪用
  // paint() 里用 strokeWidth 2.0 + StrokeCap.round 描边
}
