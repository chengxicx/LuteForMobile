三、隔离措施

「不污染其他应用」是本次的核心约束，具体落到了以下几点：

做法说明
未安装 任何 apt 包 flutter analyze、pub get、build apk 都不需要 clang / cmake / ninja （那是 Linux 桌面构建才需要的）。安装前后软件包数量均为 608，未变。
独立目录 SDK 放在 /opt/flutter，源码副本放在 /opt/lute_mobile_src， 与生产目录 /opt/lute 完全分离。
仅新增文件 PATH 通过新建的 /etc/profile.d/flutter.sh 暴露， 未修改 ~/.bashrc 或任何已有配置文件。
缓存隔离 PUB_CACHE 指向 SDK 目录内，不写入 ~/.pub-cache。
未重启服务 全程未执行任何 systemctl restart；事后复核三个服务仍为 active， 端口 5001 / 80 / 3306 监听正常。
关闭遥测 已执行 flutter config --no-analytics，避免额外外发数据。

六、使用与回滚

日常用法

非交互式 SSH 不会自动加载 profile.d，需显式导出环境变量：

# 同步最新源码
cd /Users/cxi/Documents/lutedev/LuteForMobile
tar -cf - --exclude='./.git' --exclude='./.dart_tool' --exclude='./dist' \
    --exclude='./.workbuddy-ai' --exclude='./build' --exclude='.DS_Store' . \
  | ssh root@172.236.226.132 \
    'rm -rf /opt/lute_mobile_src; mkdir -p /opt/lute_mobile_src; tar -xf - -C /opt/lute_mobile_src'

# 静态分析
ssh root@172.236.226.132 \
  'export FLUTTER_HOME=/opt/flutter; export PUB_CACHE=/opt/flutter/.pub-cache;
   export PATH="$FLUTTER_HOME/bin:$FLUTTER_HOME/bin/cache/dart-sdk/bin:$PATH";
   cd /opt/lute_mobile_src && flutter pub get && flutter analyze'

完整回滚

本次所有改动都集中在下面几处，删除即可完全还原，不影响任何生产服务：

rm -rf /opt/flutter /opt/lute_mobile_src
rm -f /etc/profile.d/flutter.sh
