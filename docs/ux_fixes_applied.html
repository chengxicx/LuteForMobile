四、附带修掉的两个真实 bug

1. 书架打不开（type 'Null' is not a subtype of type 'int'）

真机联调时发现：Book.fromJson 用了强制类型转换 （json['PageCount'] as int 等），服务端任一字段返回 null 就会让整页书架崩溃。服务端 SQL 里确实存在 case when … else currtext.TxOrder end as PageNum 这类可能算出 NULL 的表达式。

顺着这条线索做了**全项目排查**，又找出 6 处同类脆弱点 （books 列表解析入口、语言映射、统计页、词条列表、缓存解析等）， 统一改成容错转换。**这是代码里原本就存在的缺陷，不是本次 UI 改动引入的。**

2. 黑白主题状态色有 4 对完全相同

status0 与 status4 都是 #999999；status1 / status98 / status99 三个都是 #000000（ΔE = 0）。 且 Learning5 上的白字对比度只有 1.61，几乎看不见。已按"越熟越浅"的语义重排为 8 级灰阶。
