根因与修复
  • 释义丢失：App 解析 /read/termpopup 时固定取第 2 个 <p>；日语词带假名读音段 <p><i>うごきます</i></p>，读音被当成释义，真释义被丢弃。→ 改为逐段跳过 flash 提示 / 纯斜体读音段 / Components 标题，并排除 parents·components 分区（body 直接子段落才参与），取第一个普通段落为释义。
  • 看不清：e-ink 上半透明灰字（alpha 0.7）、20% 透明细边框、高斯阴影量化后全部糊掉。→ 墨水屏下：释义用正文字号 + 全不透明，1.5px 实线描边，去掉 elevation/阴影/淡入缩放动画（防残影）。
  • 消失太快：固定 3 秒自动关闭。→ 墨水屏 10 秒，其余设备保持 3 秒；点卡片随时可手动关闭。
